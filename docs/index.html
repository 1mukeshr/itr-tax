Requirements

Install these before you run the app.

NeedDetails
PHP8.3+ with pdo_mysql, mysqli, openssl, curl, zip, mbstring, fileinfo, intl
Composer2.x
DatabaseMySQL 8+ or MariaDB 10.5+
Serverphp artisan serve locally, or Apache/Nginx → public/
OptionalNode/npm only for Vite · Razorpay keys for live payments

Run locally (Windows)

From the project root folder (not a fixed drive path).

$env:PHPRC = (Get-Location).Path

.\tools\start-mysql.bat
php tools\setup-mysql.php
php artisan migrate:fresh --seed

php artisan serve --host=127.0.0.1 --port=8000
php artisan serve --host=127.0.0.1 --port=8001
Main site http://127.0.0.1:8000
Admin (admin / admin@2026) http://127.0.0.1:8001/login
